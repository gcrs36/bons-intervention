# Installer et utiliser GCRS Interventions hors ligne

## Après le déploiement Render

Ouvrir une première fois l’adresse suivante avec Internet :

`https://bons-intervention-8b20.onrender.com/`

Attendre que la page soit complètement affichée avant de l’installer.

## Installer sur un ordinateur Windows ou Mac

1. Ouvrir l’application dans Chrome ou Microsoft Edge.
2. Cliquer sur **Installer l’application** dans GCRS Interventions.
3. Si le navigateur ne présente pas encore la fenêtre, ouvrir son menu puis choisir **Installer GCRS Interventions**.
4. Confirmer l’installation.

L’application possède ensuite sa propre icône et s’ouvre dans une fenêtre indépendante.

## Installer sur Android

1. Ouvrir l’application dans Chrome.
2. Appuyer sur **Installer l’application** ou ouvrir le menu de Chrome.
3. Choisir **Installer l’application** ou **Ajouter à l’écran d’accueil**.

## Installer sur iPhone ou iPad

1. Ouvrir l’application dans Safari.
2. Appuyer sur le bouton **Partager**.
3. Choisir **Sur l’écran d’accueil**.
4. Appuyer sur **Ajouter**.

## Créer un bon sans Internet

1. Ouvrir l’application installée.
2. Choisir **Nouveau document**.
3. Choisir la **société** : GCRS, Dimensions, ESI, ABEG ou ARBOREAL.
4. Choisir l’un des bons proposés pour cette société.
5. Remplir et signer le formulaire correspondant au PDF choisi.
6. Appuyer sur **Enregistrer**.

Une référence contenant `LOCAL` est créée. Le bon apparaît dans l’historique avec l’état **Hors ligne**. Les données, photos et signatures restent sur l’appareil.

Le PDF ne peut être généré qu’après la reconnexion, car sa mise en page et son archivage sont réalisés par le serveur.

## Après le retour d’Internet

L’application essaie automatiquement d’envoyer les bons en attente. Il est également possible d’ouvrir **Historique** puis d’appuyer sur **Envoyer maintenant**.

Après l’envoi :

1. la référence locale est remplacée par la référence définitive ;
2. le PDF devient disponible ;
3. si l’option Dolibarr était cochée, la fiche d’intervention, la commande éventuelle et la facture brouillon sont préparées.

## Précautions importantes

- Ne pas vider les données du navigateur ou désinstaller l’application tant qu’un bon porte l’état **Hors ligne**.
- Protéger le téléphone, la tablette ou l’ordinateur par un code ou un mot de passe : les bons en attente sont stockés localement.
- Ouvrir périodiquement l’application avec Internet pour recevoir les nouvelles versions des formulaires.
