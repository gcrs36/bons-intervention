# Version 2.0

## Interface

- nouveau tableau de bord professionnel ;
- historique filtrable et responsive ;
- formulaire mobile en six étapes ;
- recherche de clients Dolibarr ;
- plusieurs pièces par intervention avec calcul automatique ;
- signature tactile améliorée ;
- PDF A4 entièrement redessiné ;
- export Excel réparé et enrichi.

## Dolibarr

- connecteur REST exécuté uniquement côté serveur ;
- recherche ou création du tiers ;
- création d’une fiche d’intervention avec durée ;
- ajout du PDF signé à l’intervention ;
- création d’une commande brouillon si des pièces sont présentes ;
- création d’une facture brouillon ;
- reprise d’une synchronisation partielle sans recréer les objets déjà enregistrés ;
- identifiants et erreurs Dolibarr visibles dans l’historique.

## Exploitation

- schéma SQLite migré automatiquement ;
- stockage persistant configurable ;
- authentification HTTP configurable ;
- export Excel à deux feuilles ;
- configuration Render documentée ;
- tests unitaires du flux Dolibarr.
